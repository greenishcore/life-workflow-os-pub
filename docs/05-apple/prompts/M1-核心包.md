# M1：LifeWorkflowKit 共享核心包

> 前置：先读 `00-总纲.md`。本文只写 M1 特有内容。

## 1. 角色
资深 Swift 库作者。你写的是**要被三个平台依赖十年**的地基代码，
优先级是：正确性 > 可测性 > 可读性 > 性能 > 简洁。

## 2. 背景
Python 版 `lifeos/` 的非 UI 部分（config / models / frontmatter / repository / stats /
services）是**已验证的规格**，`tests/test_lifeos.py` 的 44 项测试是**行为契约**。
本任务把这层翻成 Swift，供后续三端复用。

## 3. 目标
交付 Swift Package `LifeWorkflowKit`，包含：

| 模块 | 对应 Python | 职责 |
|------|-------------|------|
| `Models` | `models.py` | `Item` / `ThinkingNote` / `RunLog` / `Status` / `Priority` / `ItemType` |
| `Frontmatter` | `frontmatter.py` | 确定性 YAML 解析与序列化 |
| `VaultStore` | `repository.py` | 扫描 / 索引 / CRUD / 原子写 / 回收站 / 捕获 / 段落更新 |
| `Stats` | `stats.py` | 热力图 / 状态分布 / 生命线 / 标签 / 连续活跃 / 摘要 |
| `Config` | `config.py` | 单一配置源（含 iCloud 容器解析） |
| `Services` | `services/` | EventKit 桥 / 转换任务 / 运行日志 / 周复盘 |

## 4. 约束（在总纲之上追加）
- `Item` 等模型必须是 `Sendable` 的值类型；`VaultStore` 用 `actor` 保证并发安全。
- **不使用 SwiftData / CoreData**：事实源是文件，不是数据库。
- YAML 解析**自己实现**（只需支持本项目 frontmatter 的子集），
  不引入 Yams 等第三方——理由：序列化的确定性要求比通用性重要，且要与 Python 版逐字节对齐。
- 路径处理必须支持**安全作用域书签**（security-scoped bookmark），
  否则 iOS/沙盒 macOS 重启后拿不到 vault 访问权。
- 文件名清洗规则与 Python 版一致（`/ \ : * ? " < > |` 与换行符 → `-`，去重加序号，截断 80 字符）。

## 5. 输出格式
```
LifeWorkflowKit/
├── Package.swift            平台：macOS 14+ / iOS 17+ / watchOS 10+
├── Sources/LifeWorkflowKit/
│   ├── Models/              Item.swift  ThinkingNote.swift  RunLog.swift  Enums.swift
│   ├── Frontmatter/         Parser.swift  Emitter.swift
│   ├── Store/               VaultStore.swift  AtomicWrite.swift  Bookmarks.swift
│   ├── Stats/               Aggregations.swift
│   ├── Config/              AppConfig.swift
│   └── Services/            EventKitBridge.swift  RunLogService.swift  ReviewService.swift
└── Tests/LifeWorkflowKitTests/   与 Python 44 项逐条对应
```

## 6. 验收标准
- [ ] `swift test` 全绿，用例数 ≥ 44，且**每个用例注释里标明对应的 Python 用例名**；
- [ ] 幂等性专项：读取 `vault/` 下全部真实笔记 → 写回 → `diff` 无差异；
- [ ] 交叉验证：提供 `Tools/crossvalidate.swift`（或脚本），
      对同一批笔记分别用 Python 与 Swift 解析，比对 JSON 化后的模型**完全相等**；
- [ ] 特殊字符往返测试覆盖：`, : " [ ] { } #`、换行、纯数字串、日期形态串、空字符串、超长标题；
- [ ] 并发安全：`swift test` 在 `-strict-concurrency=complete` 下零警告；
      并有一个用例并发写入 100 条记录后校验无损坏、无 `.tmp` 残留；
- [ ] `VaultStore` 在 vault 不存在 / 无权限 / 磁盘满 三种情况下返回明确错误，不崩溃。

## 7. 待确认问题
1. `Config` 的落点：沿用 `~/.config/lifeos/config.json`（与 Python 版共享），
   还是改用 `UserDefaults` + App Group？**建议前者**，保证两版本互通。
2. EventKit 桥是否放进核心包（watchOS 需编译通过但只读）？**建议放**，用可用性标注隔离。
