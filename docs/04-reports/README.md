# 阶段性报告（Reports）

本目录存放随项目推进产出的阶段性报告。报告遵循「检索 → 整合 → 规划 → 输出」的节奏。

## 计划产出

| 编号 | 报告 | 内容 | 状态 |
|------|------|------|------|
| R1 | 检索调研汇总 | 三路调研（Apple/Obsidian、格式转换/日志/提示词、GitHub/看板）的合并结论 | ⏳ 进行中 |
| R2 | 架构整合报告 | 五阶段闭环 + 数据模型 + 信息流拓扑 + 工具映射 | ⏳ 待产出 |
| R3 | 分阶段实施规划 | 7 个 Phase 的实施顺序、交付物、验收标准、里程碑 | ⏳ 待产出 |
| R4 | 阶段总结（迭代产出） | 每个 Phase 完成后的复盘与下一阶段调整 | 📅 随阶段推进 |

## 报告命名约定

- 一次性报告：`2025-xx-xx-<标题>.md`
- 迭代性复盘：`weekly-YYYY-Wxx.md` / `monthly-YYYY-MM.md`
