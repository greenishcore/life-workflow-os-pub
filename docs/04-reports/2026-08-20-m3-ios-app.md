## 一、先说一个决定方案的前提

M3 提示词的前置写的是「vault 已在 iCloud Drive 容器」。但调研时定的是**免费 Apple ID**，
而 **iCloud 容器权益要付费开发者账号**——照原方案走不通。

检索确认了一条不需要任何权益的替代路径：
`UIDocumentPickerViewController` 可以让用户选中 **iCloud Drive 里的文件夹**
（路径形如 `/private/var/mobile/Library/Mobile Documents/com~apple~CloudDocs/…`），
再用书签持久化访问权，每次使用前 `startAccessingSecurityScopedResource()`。

所以 iOS 端改成：**用户自己选目录 + 书签记住授权**。效果与 iCloud 容器一致
（同一份 Markdown 文件、Mac 与 Obsidian 都能读写），且免费账号可用。
Obsidian iOS 走的也是这条路。

### 3.1 iOS Simulator 集成受阻，用了替代方案

Claude Code 的 iOS Simulator 工具报错：
`Xcode is installed but not selected. Run sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`。
这条命令需要密码，只能由你执行。

在此之前改用 `xcrun simctl install / launch / io screenshot` 验证——
能装机、能启动、能截图，但**无法注入点击与输入**。因此给 iOS 应用加了
`--tab <名称>` 启动参数来切换标签页截图（与 macOS 的 `--snapshot` 同思路）。

**这意味着**：所有页面的渲染与数据读取已验证；**点击、输入、滑动等交互
未经自动化验证**，需要你在模拟器或真机上手动确认。
